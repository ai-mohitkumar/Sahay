# Sahay Master Roadmap

- [x] **Step 0 — One-Line Pitch & Identity**: "An AI that negotiates your day with you, not just schedules it." Name: **Sahay**.
- [x] **Step 1 — Developer Foundation**: FastAPI + React 18 + Vite + Tailwind + SQLite setup.
- [x] **Step 2 — 7-Table Core Database Design**: `users`, `exams`, `goals`, `subjects`, `tasks`, `schedules`, `activity_history`.
- [x] **Step 3 — Circadian Onboarding Wizard**: Wake/sleep times, fixed commitments (college/coaching), exam target, subjects.
- [x] **Step 4 — 24-Hour Vertical Timeline**: Visual timeline with time markers, current cursor, color coding for fixed vs focus blocks.
- [x] **Step 5 — Action & Activity Ledger**: Complete, Skip, and Postpone actions recording planned vs actual durations in `activity_history`.
- [x] **Step 7/8 — The Trade-Off Engine**: AI consequence evaluator + negotiation counter-offers for student schedule friction.
- [x] **Step 9 — Future Self Simulation**: 30-day forward projection of exam readiness curve, cumulative focus hours, and burnout probability.
- [ ] **Phase 2 — Social Accountability Pods**: 3-5 person student pods prepping for the same exam with aggregate pacing benchmarks.
